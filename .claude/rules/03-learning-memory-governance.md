# حاکمیت یادگیری، تحقیق و حافظه

چرخه‌ی رسمی:

`OBSERVATION → QUESTION → SOURCES → EVIDENCE → HYPOTHESIS → BACKTEST → WALK_FORWARD → PAPER → SHADOW → REVIEW → VERSIONED_PROMOTION`

- یادگیری از نظر موضوعی محدود نمی‌شود، اما ورود آن به Production کاملاً کنترل می‌شود.
- Random browsing و خواندن کل GitHub ممنوع است؛ هر تحقیق سؤال دقیق و Source Hierarchy دارد.
- وضعیت Claim: UNVERIFIED, RESEARCHED, BACKTESTED, PAPER_VALIDATED, SHADOW_VALIDATED, PRODUCTION_VALIDATED, REJECTED.
- تنها Memory Curator می‌تواند Canonical Memory را تغییر دهد.
- Idle compute به Replay/Backtest/Research Queue اختصاص می‌یابد، نه فراخوانی دائمی LLM.
- هر Claim: source, URL/reference, retrieved_at, agent, claim, evidence, sample_size, regime, confidence, validation_status, strategy_version.
- Conflict حذف نمی‌شود؛ Versioned و قابل مشاهده می‌ماند.
- تغییر وزن یا Threshold باید Out-of-sample و Regime split داشته باشد.

## اصل انباشت تجربه (دستور حمید، ۲۳ اوت)

«با هر یک ترید و علت‌یابی و نتیجه‌گیری، تو با آدم قبلی فرق می‌کنی… هر بار
بعد از یادگیری، تو ایجنتی با تجربهٔ بیشتری هستی که تصمیم نهایی را می‌گیرد.»

سه تعهد که از این اصل بیرون می‌آید — هر سه اجباری:

1. **هر معاملهٔ بسته در همان چرخه هضم می‌شود** (`memory.digest_closed`):
   پروندهٔ علت در `brain/cases/`، و اگر قابل تعمیم بود درس در
   `brain/memory/lessons.json`. تریدِ بی‌علت‌یابی، تجربه نیست.
2. **تصمیم بعدی باید همان رکورد را بخواند.** کارنامهٔ (ارز، جهت) قبل از
   صدور پرسیده می‌شود و اتاق یادگیری ستاپ با رکورد بدِ نمونه‌دار را نگه
   می‌دارد. تغییری که نتواند تصمیم آینده را عوض کند، یادگیری نیست.
3. **بزرگیِ بهبود اندازه گرفته می‌شود، ادعا نمی‌شود.** هر ادعای «تجربه
   کمک کرد» فقط با CI ردشده از صفر (ماشین بونفرونی) گزارش می‌شود.

### چرا بند ۳ حیاتی است — نمونهٔ عددی ۲۳ اوت

| نمونه | n (با/بدون) | اختلاف | CI95 | حکم |
|---|---|---|---|---|
| دفتر چندروزه | ۱۳۳ با تجربه | **+۰.۴۴۳R** | [+۰.۰۳۷, +۰.۸۳۹] | معنادار |
| فقط همان یک روز | ۵۷ / ۸۰ | −۰.۰۷۰R | [−۰.۳۷۴, +۰.۲۵۱] | **از نویز جدا نیست** |

هر دو درست‌اند؛ فرق در اندازهٔ نمونه است. پس **یک روزِ خوب یا بد،
یادگیری را نه اثبات می‌کند نه رد** — و گزارشِ روزانه حق ندارد اثر
یادگیری را از نمونهٔ یک‌روزه نتیجه بگیرد.
