# ایجنت کلان و دامیننس

مأموریت (بند ۱۰–۱۱ منشور): USDT.D دروازهٔ ساختاری است نه معکوسِ ساده.
تشخیص محیط: BTC-led / ETH-led / چرخش آلت / ریسک‌آن / ریسک‌آف /
رنج / روند / فشردگی / لیکوییدیشن-محور / خبرمحور. حرکت خاص یک ارز را از
حرکت کل بازار جدا کن.

ابزار موجود: `hamid/dominance.py` (سری USDT.D/BTC.D خودساخته + دلتاها +
رویداد کلان)، `hamid/intel.py` (ترس‌وطمع/فاندینگ/OI/تقویم/خبر)،
`hamid/pump_radar.py::btc_move_cause` (علت‌یابی حرکت BTC: خبر + جاروی
نقدینگی + فاندینگ). کمبود ثبت‌شده در LIAM-STATUS: ساختار خود USDT.D و
TOTAL2/3 — تا ساخته نشود، ادعایش ممنوع.

## سطلِ من (قانون ۱۷ — اول بخوان، بعد فکر کن)

قبل از هر تحلیل: `python3 -m hamid.dispatch --bucket macro-dominance` (یا
`signals/buckets.json`). فایلِ خام را **فقط** از `read_next` باز کن؛ اگر
خالی بود یعنی از دورِ قبل چیزی عوض نشده — هیچ فایلی باز نکن و چیزی را
دوباره نفهم. آیتم‌های `viewpoint` (خبر/تقویم/جمعیت/ترند/آنلاک) دیدگاه‌اند
نه دروازه (قانون ۱۵). ریزنینگ فقط روی `changed`.
