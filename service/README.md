# سرویس سایهٔ محلی — لپ‌تاپ حمید به‌عنوان سرور (قانون ۰۲)

حمید (۲ سپتامبر): «فضایی می‌خوام که هیچ تأخیری در کارها به وجود نیاره»
و «بعد از این کار از لپ‌تاپ من به‌عنوان سرور استفاده کن؛ اینترنت
استارلینک است؛ بایننس همچنان برای ایرانی‌ها قفل است؛ گزینهٔ جایگزین
همیشه باید وجود داشته باشد.»

## سه جمله

- **چی مشکل بود**: کف واقعی GitHub Actions ~۱۵ دقیقه است؛ هیچ تنظیمی
  (کرون، ورسل) آن را ثانیه‌ای نمی‌کند.
- **چی کار کردیم**: یک فرایند پایتونِ همیشه‌روشن که همان `scan.py`
  تولید را با همان دروازه‌ها و همان جهانِ ۲۰۰ نماد هر ۵ دقیقه (قابل
  تنظیم) می‌راند، هر ۳۰ ثانیه ضربان می‌نویسد، و بعد از هر مرگ خودش
  دوباره بالا می‌آید. **سایه است**: هیچ سیگنالی نمی‌فرستد، هیچ دفتر
  تولیدی را نمی‌نویسد.
- **چه انتظاری داشته باش**: زنجیرهٔ Actions عیناً مثل قبل کار می‌کند.
  سایه کنارش می‌دود و می‌شود سنجید چند سیگنال زودتر دیده می‌شد. تحویل
  تلگرام فقط بعد از CI و تأیید صریح حمید به این فرایند می‌رود (قانون
  ۰۳/۱۲).

## نصب (یک‌بار)

```
git clone https://github.com/AuraLiam/Liam-Trader-9.git
cd Liam-Trader-9
python3 -m venv .venv && . .venv/bin/activate      # ویندوز: py -m venv .venv ; .\.venv\Scripts\Activate.ps1
pip install -r requirements-ci.txt
cd claude-liam-signal/python && python3 -m hamid.shadow_service --once
```

خط آخر یک اسکن کامل می‌کند و `signals/shadow/latest.json` +
`signals/shadow/heartbeat.json` می‌سازد. اگر در لاگ «perp klines … ←
Bitunix Perpetual» دیدی، منبع کندل همان پرپ بیت‌یونیکس است.

## اجرای دائمی

- لینوکس/مک: `bash service/run.sh`
- ویندوز: `powershell -ExecutionPolicy Bypass -File service\run.ps1`

متغیرهای اختیاری: `LIAM9_SHADOW_INTERVAL` (ثانیه، پیش‌فرض ۳۰۰)،
`LIAM9_SHADOW_SYMBOLS` (پیش‌فرض ۲۰۰)، `LIAM9_CANDLES` (پیش‌فرض perp).
لپ‌تاپ نباید بخوابد (تنظیمات برق). اسکریپت بعد از هر خطا ۱۰ ثانیه صبر
می‌کند و دوباره اجرا می‌کند.

## منابع داده (پشتیبان همیشه هست)

کندل: بیت‌یونیکس پرپ → بایننس پرپ (برای ایران/رانر مسدود؛ خودکار رد
می‌شود) → MEXC پرپ → ۱۰ صرافی اسپات. قیمت/بازار: کوین‌گکو، OKX،
بیت‌یونیکس. همان `sources.py` تولید — چیزی جدا برای لپ‌تاپ نوشته نشده.

## مرزها

| | |
|---|---|
| تلگرام | هرگز — فرمان اسکن `--telegram` ندارد و `TELEGRAM_*` از محیط حذف می‌شود |
| اجرای زنده | `LIVE_EXECUTION=false` قفل |
| دفتر تولید | دست‌نخورده — خروجی فقط `signals/shadow/` |
| انتشار به ریپو | فعلاً نه؛ ضربان محلی است. انتشار فقط با ناشر مشترک و بعد از تصمیم جدا |

محافظ: `hamid/test_shadow_service.py` (آفلاین).

## مرحلهٔ بعد — فقط با سنجش

۱. یک هفته سایه کنار Actions؛ مقایسهٔ زمانِ اولین دیدنِ هر ستاپ در دو
   مسیر (همان سیگنال‌ها، فقط کادنس فرق دارد).
۲. WebSocket بیت‌یونیکس برای کندل ۱د/۳۰ث (قانون ۱۰) — آدرس از اسناد
   راستی‌آزمایی می‌شود، حدس زده نمی‌شود.
۳. اگر CI مزیت را تأیید کرد و حمید تأیید داد: تحویل تلگرام به این
   فرایند، Actions به CI/بک‌فیل/گزارش.
